# 🎮 Frontend Inteligente

Um site moderno de jogos em estilo neon futurista, desenvolvido com HTML, CSS e JavaScript. O projeto reúne diversos minigames interativos em uma interface responsiva, animada e com visual inspirado em plataformas gamers.

---

# ✨ Visão Geral

O objetivo do projeto é criar uma experiência divertida e moderna diretamente no navegador, com jogos rápidos, leves e responsivos.

O site possui:

* Interface neon futurista
* Layout responsivo
* Cards animados
* Botões modernos com efeitos glow
* Jogos multiplayer locais
* Sistema visual estilizado
* Experiência otimizada para celular e PC

---

# 🕹️ Jogos Disponíveis

## 🧠 Genius

Teste sua memória repetindo sequências cada vez maiores.

### Recursos

* Sistema de rounds
* Recorde
* Efeitos sonoros/visuais
* Velocidade progressiva

---

## ⭕ Jogo da Velha

Entre X e O, nasce uma batalha de estratégia, reflexo e rivalidade.
No brilho neon do tabuleiro, cada movimento pode ser o último… ou o que vai te levar à vitória.

### Recursos

* Multiplayer local
* Interface neon
* Sistema de vitória
* Reinício rápido

---

## 🔢 Adivinhação

Descubra o número secreto antes do limite acabar.

### Recursos

* Níveis de dificuldade
* Sistema de dicas
* Contador de tentativas
* Interface moderna

---

## ✊ Pedra Papel Tesoura

Vença seu rival em rounds rápidos e estratégicos.

### Recursos

* Multiplayer local
* Escolha aleatória
* Sistema de placar
* Popup de resultados
* Rodadas rápidas

# 🚀 Como Executar

## 1. Baixe os arquivos

Clone ou baixe o projeto:

```bash
git clone https://github.com/Fpadilha3/PaginaDeJogos.git
```

---

## 2. Abra o projeto

Abra o arquivo:

```bash
index.html
```

em qualquer navegador.
